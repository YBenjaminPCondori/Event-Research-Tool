# StandScout Frontend

Next.js frontend for StandScout.

## Run from VS Code

1. Open this `frontend` folder in VS Code.
2. Install the Node packages from `package.json`.
3. Copy `.env.local.example` to `.env.local` if needed.
4. Start the Next.js dev server.
5. Open `http://localhost:3000`.

The frontend expects the Python API at:

`http://127.0.0.1:8000`

Change this in `.env.local` if your backend runs elsewhere.
